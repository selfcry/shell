# Что известно из публичной документации SmartShell (support.smartshell.gg)

Источник: открытая справка. Это пример устройства *клиентской оболочки* (шелла) и админ-панели. Копировать код и дизайн не нужно — берём идеи.

## Шелл подменяет рабочий стол
- Установщик спрашивает логин менеджера, клуб, название ПК (3–12 символов) и группу хостов (зал). После установки — перезагрузка, шелл стартует вместо рабочего стола.
- **Режим «высокого доступа»**: на ПК Ctrl+Alt+P + пароль (по умолчанию `pasw0rd` — у нас такого быть не должно) или командой из панели. В нём редактируют ярлыки и могут **отключить шелл** (кнопка «выход в Windows»). Из панели: ПК → Шелл → Высокий доступ / Отключить шелл.
- Autologon: служебный `Autologon.exe`, пароль учётки обязателен, Windows Hello не работает.
- Бездисковые системы: ставим на мастер-образ, шелл деактивируем (Ctrl+Alt+P), сохраняем образ, после раскатки активируем.

## Каталог игр и приложений (центральный, с автоподтягиванием)
Карточка: название (2–50 символов), **до 3 путей запуска**, аргументы, скрипт до запуска, рабочая папка, пароль запуска (заготовка), группа клубных аккаунтов, возрастное ограничение (требует регистрации), «запускать от администратора», обложка (2:3, 600×900, ≤250 КБ, jpg/png), группа игр, описание, скриншоты.
- Шелл при каждом запуске проверяет все пути и показывает гостю **только найденные на этом ПК** приложения. Каталог ведётся один раз, на остальные ПК подтягивается сам.
- Рецепты запуска: Steam `steam://rungameid/ID` (или `Steam.exe -applaunch ID`), Epic `com.epicgames.launcher://apps/…?action=launch&silent=true`, Riot `RiotClientServices.exe --launch-product=… --launch-patchline=live`, Ubisoft `uplay://launch/ID`, Battle.net — только путь к exe, EA — путь к лаунчеру, Microsoft Store `shell:AppsFolder/<AppID>` (AppID из `Get-StartApps`), Discord `%LOCALAPPDATA%\Discord\Update.exe --processStart Discord.exe`. Нужны переменные среды в путях.
- Клубные аккаунты: группа аккаунтов (логин/пароль, лаунчер) привязывается к карточке; аккаунт занят до конца сессии; виджет «занятые аккаунты».

## Защита гостевой сессии (настройки безопасности)
- **Блокировка окон** по заголовку и/или классу, принудительное закрытие: проводник `CabinetWClass`, консоль `ConsoleWindowClass` / `CASCADIA_HOSTING_WINDOW_CLASS`, диалоги «Открыть/Сохранить» `#32770` (ломает лаунчер PUBG), `*Microsoft Edge`, `*C:/*`. Шаблон `*слово*` — по вхождению.
- Скрытые диски (обычно C:), запрет внешних накопителей, запрет скачивания файлов в Chrome внутри шелла.
- Пароль высокого доступа применяется после перезапуска шелла (Ctrl+Alt+Del → «Выйти»).
- Удалённое управление: TightVNC с паролем (на CCBoot не работает).

## Питание и поведение
- Действие после завершения сеанса через N минут: выключение / перезапуск / выход из Windows (с Autologon перезапускается только шелл). Выключение ПК при простое. Автозапуск приложений при старте шелла.
- Wake-on-LAN: включение работает, только если в этой подсети уже включён хотя бы один клиентский ПК.
- Периферия (мышь, звук) выводится в трей шелла. Язык шелла, правила клуба (принимаются перед сеансом).
- Заставка: картинка ≤2 МБ или mp4/webm ≤30 МБ, через N минут простоя, **номер ПК поверх**. Фон 1920×1080 ≤2 МБ, цветовая схема, логотип клуба; предпросмотр в реальном времени. Для видео нужны кодеки.

## Домашняя страница гостя (после входа и принятия правил)
Профиль (сменить ПК, заблокировать ПК, завершить сеанс), кошелёк (депозит, бонусы, скидка, промокод, онлайн-пополнение, перевод между клубами), достижения (условия: часы, суммы, пополнения → награда: скидка/бонусы), рейтинг активности за месяц, рекомендуемые тарифы и товары, новости клуба, витрина тарифов и магазин. «Позвать админа» (повтор через 1 минуту), отзыв с чаевыми после сеанса.
- Регистрация: дата рождения, ник, пароль, телефон, e-mail, согласия; подтверждение **бесплатным звонком гостя на номер**, запасные способы — код входящим звонком, Telegram, VK, e-mail. **Единая база клиентов** на все клубы, условия (депозит, бонусы, скидка) свои в каждом.
- Тарифы: время сгорает при выходе (кроме абонемента), можно купить несколько одинаковых, абонемент нельзя купить при активном тарифе; самостоятельная пересадка с переносом сеанса; пересадка между залами только в зал с меньшим приоритетом.

## Админ-панель
- Вкладки: Дашборд, Компьютеры (таблица и карта), Бронирование, Магазин, Платежи, Клиенты, Логи; дополнительное меню: объявления, тарифы, товары/услуги/комбо, лояльность, сотрудники, отзывы, клубные аккаунты, игры и приложения, аналитика, настройки, новости.
- **Статусы ПК**: Занят, Свободен, Выключен, В обслуживании, **Нет связи** (нет пинга от хоста дольше 1 минуты), Высокий доступ, **Снят шелл**, Заблокирован (гость закрыл ПК на время сеанса), **Изменена конфигурация** (требует подтверждения менеджера, плюс Telegram).
- **Карта клуба** с редактором (одна клетка — один элемент): ПК, консоль, VR, автосимулятор, бильярд, настолки; стены, ресепшен, гардероб, лаунж, бар, кухня; группы хостов = залы с приоритетом.
- Контекстное меню ПК: выбрать тариф, пополнить депозит, бронь, **штраф** (время минус, текстовое и звуковое уведомление), смена места (в рамках зала), завершить сеанс, уведомление, питание, управление ПК (VNC, просмотр экрана), шелл (высокий доступ / отключить). Массовое выделение (Shift/Ctrl, «выбрать все в зале»): массовая продажа тарифа в одном зале, уведомления, бронь, питание.
- Техсостояние ПК: процессор, ОЗУ, видеокарта, диск, MAC, активное приложение, комментарий.
- Смена: открытие с суммой наличных, пополнение (Ctrl+Alt+D, массовое), посадка (гостевой сеанс без аккаунта), запрет пополнять/сажать самого себя при открытой смене, смена не закрывается при неоплаченной постоплате. **Постоплата** (поминутно, оплата после, макс. 5–1440 мин).
- Регистрация клиента оператором: пароль = телефон, при первом входе предложение сменить.

# Что видно в публичном демо SmartShell (demo.smartshell.gg)

## Админ-панель (веб, светлая тема, переключатель темы в меню сотрудника)
- Верх: логотип, кнопка **«Open client shell»** (открывает гостевую оболочку прямо в панели как выезжающую панель, удобно для предпросмотра), «+» быстрое меню оператора, поиск клиента по телефону/нику, меню сотрудника.
- Меню слева (сворачиваемое): Dashboard, Gaming stations (таблица), Map, Booking system, Shop, Payments, Clients, Logs, Goods and services ›, Loyalty system ›, Employees, Client reviews (бейдж с числом), Content ›, Analytics, Listings, Settings. Внизу кнопка «Register your club». Первый вход — обучающий тур на 45 шагов.
- **Dashboard**: карточка оператора и время начала смены; выручка (нал / безнал с процентами); наличные в кассе и на начало смены; плитки: проходки, товары, пополнения, услуги; расходы депозита, бонусные пополнения, онлайн-пополнения; **строка состояния парка** (игровых станций, включено, активных сессий, в обслуживании, высокий доступ, шелл снят); задачи персонала с дедлайном и ответственным.
- **Gaming stations**: плашки проблем сверху («Shell deactivated | 1», «In service | 2»), группы-залы, колонки: №, название, статус (In use / Turned on…), бронь, клиент (ссылкой), тариф, начало, конец, **осталось**, приложение, версия. Выбрать всё в зале, шестерёнка настроек зала.
- **Контекстное меню ПК (ПКМ)**: Select rate, Post-payment, Replenish deposit, Booking system ›, Penalty ›, Transfer, QR code for TV linking, **End session** (красным), Notification, Power supply ›, PC control ›, Shell ›.
- **Map**: сетка клеток; залы разными цветами (подписи зон на карте), на плитке номер места, **таймер до конца сеанса**, значки «есть бронь» и «нет связи/сломан»; стены, диваны (зоны отдыха); масштаб 100 % с кнопками +/−; карандаш = режим редактирования; фильтр «показывать только хосты».

## Клиентская оболочка (шелл) — это и есть «свой рабочий стол»
- Тёмная тема, фон-иллюстрация, лево — узкая колонка с логотипом и иконкой раздела, внизу номер ПК/IP.
- Верх: вкладки **Games | Applications**, плашка «PC-10 · Online» (имя ПК + статус связи) и кнопка **Sign in**, справа карточка «Guest» («войдите, чтобы копить бонусы, участвовать в рейтингах и сохранять прогресс») со значком выхода.
- Под вкладками: поиск по играм и **фильтры-чипсы** («All games», «Игры с клубными аккаунтами», жанровые группы), стрелки прокрутки чипсов.
- Сетка **обложек 2:3** с подписью под каждой; игры (CS2, STALKER, PUBG, L4D2) и лаунчеры (Steam, «Пополнить Steam»).
- Нижняя системная панель во всю ширину: язык, периферия (мышь), звук, сеть, трей, часы и дата.
- Вход гостя — выезжающая справа панель (телефон + пароль).
