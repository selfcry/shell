# Что известно из публичной вики Langame (wiki.langame.ru)

Заметки о том, как у них устроена клиентская часть. Источник — только открытая документация для администраторов; код не разбирался.
Цель — понять сценарии и решить, что повторить в ClubShell своими средствами.

## Установка и подготовка ПК
- Windows 10/11 **Pro**, чистый образ, локальная учётная запись с автовходом, **без сторонних антивирусов**.
- У них гость работает под администратором, UAC выключен, Defender и брандмауэр выключены, политикой убирают право сетевого доступа к ПК.
  У ClubShell другая модель: гость — обычный пользователь без админ-прав (безопаснее).
- Пароль на BIOS, статический IP (Mikrotik), Wake-on-LAN (BIOS: Resume by PCI-E, ErP off, Fast Boot off).
- Клиент ПК проходит аутентификацию **клиентским сертификатом** (.p12 в хранилище «Личное» текущего пользователя).
  Без него сервер отвечает 401. Идентификатор ПК — UUID материнской платы (для бездисковой загрузки CCBOOT — от MAC-адреса).
- Поддержка дисковой и бездисковой (CCBOOT) архитектуры.

## Режимы ПК
- Статусы: Свободен, Занят, Соединение (нет связи с сервером).
- **Технический режим** («Тех. старт» / «Тех. стоп»): диск не заморожен, можно ставить игры. Максимальное время режима ограничивается
  (например 1440 мин), есть контроль «нелегитимного» входа в тех. режим и ручной разблокировки.
- **Заморозка диска** (в логике — Windows UWF): выбранные диски откатываются после перезагрузки; размер оверлея ≥ 8000 МБ,
  предупреждение гостю при 80–90 % заполнения, перезагрузка при 90–95 %; файл подкачки ≥ 10000 МБ меняется только через их ПО.
  Исключения по путям и ключам реестра (античиты Vanguard/FACEIT, логи Windows, кэши шейдеров), общий размер исключений ≤ 50–100 МБ.
  Исключения применяются только в тех. режиме.
- **Удаление файлов при старте сессии** (например Steam `config\loginusers.vdf`, чтобы не оставались аккаунты предыдущего гостя).

## Сессия
- Блокировка = перезагрузка ПК (очистка состояния). Через N минут после конца сессии, если гость не продлил, ПК перезагружается.
- Пауза сессии (экран блокируется, время можно не списывать). Снять может админ или гость паролем на экране блокировки.
- Если ПК в статусе «Соединение», он **перезагружается через 15 минут** (настраивается); сессия сбрасывается через заданное число минут.
- Ручная разблокировка без связи: на экране блокировки зажать **L+A+N** и ввести пароль (работает, только если ПК хотя бы раз выходил на связь).
- Защита от «спидхака» (подмена системного времени), контроль изменения оборудования, блокировка USB-накопителей.
- Сохранение пользовательских файлов гостя между ПК, энергосбережение мониторов и ПК, закрытие ЛК при бездействии.
- Пароль гостя при продлении сессии (можно отключить), бонусные баллы, кредитная линия, брони (мягкая и жёсткая), ТВ-сессии.

## Авиарежим (офлайн)
- Админ вводит **одноразовый пароль** (генерирует поддержка заранее) → ПК отключаются от домена, активные сессии замораживаются,
  разблокированными остаются только занятые ПК, остальные заблокированы. Доступны блок, разблок, перезагрузка, выключение, включение (WoL).
  Блокировка в этом режиме тоже перезагружает ПК. Попытки входа пишутся в журнал.

## Игровые аккаунты
- Справочник игр, справочник аккаунтов, «настройка запуска» (игра + лаунчер + App ID + основной аккаунт + доп. аккаунт для второго лаунчера).
- Steam: автоматический вход через **SteamCMD**, Steam Guard — коды из почты (настраивается отдельно). Epic Games тоже автоматически.
  Остальные лаунчеры (Riot, VK Play, Genshin, WoT) — ручной режим: гость и админ получают уведомление.
- Аккаунт закрепляется за ПК, пока занят; журналы использования и нехватки игр.
- Для автовхода на ПК нужен .NET Desktop Runtime 6.

## Контроль процессов
- Мониторинг активных процессов → журнал (дата + ПК), группировка по нагрузке/пути/имени.
- Списки **разрешённых** и **запрещённых** (по **MD5-хешу** файла), группы процессов, блокировка прямо из журнала.
- Файл hosts: блокировка сайтов на гостевых ПК централизованно.

## Экран блокировки и интерфейс гостя
- Заставка: JPG ≤ 2 МБ или WEBM ≤ 300 МБ, файлы хранятся локально в `C:\adv`, проверка по хешу; номер ПК поверх заставки.
- Экран входа: регистрация (ФИО, телефон, пароль, e-mail, согласия), вход по телефону+паролю или **QR из мобильного приложения**,
  восстановление пароля по SMS, дополнительные кнопки-страницы (правила, оферта, прайс).
- Кабинет открывается ярлыком/значком в трее; ярлыки на разделы запускаются аргументами `LanGameNotifyIcon page <раздел>`.
- Рабочий стол Windows остаётся; **своей оболочки вместо explorer у Langame нет**.

## Админ-часть (сервер/ПО администратора)
Смены и касса, фискализация, товары и склад, бронирования, тикеты, уведомления (Telegram/e-mail/SMS), шкафчики и реле (Sonoff, RODOS),
TV/консоли, аналитика (загрузка, retention, ARPU…), удалённое управление (LanDesk — форк RustDesk), горячие клавиши F1–F12.

# Дополнения после полного прочтения (все 253 страницы)

## Установщик и привязка ПК
- Ключи установщика для массовой установки: `/SILENT /domain=… /hdd_defender=0|1 /ccboot=0|1 /uuid=auto|<UUID> /RegisterUUIDAnyway=0|1 /userpass=…`.
- UUID — из BIOS материнской платы; у дешёвых плат бывает `FFFFFFFF-…` или одинаковый на всех: нужен ручной/случайный UUID.
- Новый ПК после установки сам появляется на сервере в списке «непривязанных» по UUID; админ задаёт номер, зону (тип ПК), клуб, цвет. После привязки ПК остаётся в техническом режиме / ручной разблокировке, пока админ не нажмёт «Тех. стоп» / «Заблокировать».
- Админ-консоль ставится отдельно (msi) с **ключом клуба**; в консоль пускают только роль «Администратор». Сервер доступен только с устройства с клиентским сертификатом (.p12).
- Удаление: перевод в тех. режим → остановка службы с домена → кнопка «Удалить ПО» → перезагрузка.

## Сессия и тарифы (модель данных)
- Типы тарифов: **базовый** (поминутно; с указанием времени или «на весь баланс»), **пакет** (фиксированная длительность или фиксированный конец, например «ночь до 06:00»), **абонемент** (время хранится на аккаунте, срок жизни, запас).
- Правила цены: тип дня (будни/выходные/праздники) × зона × интервал времени; интервал через полночь делится на два. Отдельно «время показа» и «время старта» (докупка по базовому до начала пакета).
- Минимальное время списания, возврат за неиспользованное время, макс. процент оплаты бонусами, «только в приложении», кредитная линия.
- **Динамическое ценообразование**: наценка в % от загрузки зоны (правила «от N % загрузки»), считается в момент старта сессии/брони; возврат — по базовой цене.
- Комнаты (несколько ПК = одно место, один тариф, сессия стартует на всех через мастер-ПК).
- Комбо (товары + пакет) — покупка только из ЛК на ПК, сразу запускает сессию; при сбое старта после оплаты — уведомление админу.
- Брони: информационная (не блокирует посадку) и жёсткая (блокирует за 15 минут до начала); привязка ПК за гостем до конца брони; временное отключение брони/посадки на ПК.

## Поведение клиента (настройки, влияющие на оболочку)
- Закрытие ЛК при бездействии (мин), перезагрузка после конца сессии (мин), сброс сессии если ПК недоступен (мин), перезагрузка при потере связи (по умолчанию 15 мин).
- Ввод текста перед завершением сессии (гость должен принять сообщение); обязательные уведомления поверх гостевого ПО с галочкой «ознакомлен» (и комментарий для админа).
- Чат гость ↔ админ (звук оповещения на ПК), кнопка «Сообщить о проблеме» с ограничением частоты, звуковые оповещения админа гостю (WAV/MP3/WMA, до 2 МБ, до 10 шт.).
- Самостоятельная пересадка гостя, продление сессии с проверкой пароля, открытие браузера с заданной страницей после старта (нужен Chrome по умолчанию).
- Заставку можно отключить («Не использовать заставку» → сразу окно логина), поменять фон окна авторизации, показывать номер ПК на экране блокировки (цвет настраивается).
- Админ видит у ПК: процессы, изменённые файлы, историю гостей за 12 ч, логи (смотреть/скачать), может завершить активный процесс, остановить службу, поставить паузу, временно отключить бронь.
- Массовые действия над ПК: блокировка, разблокировка, тех. старт/стоп, перезагрузка, включение (WoL), выключение.
- Тех. режим: «Тех. старт» → перезагрузка в режиме без заморозки; «Тех. стоп» → перезагрузка, диски заморожены, статус «Свободен». Обычная разблокировка заморозку **не снимает**. Из трея ПК можно локально «Заблокировать» и «Тех. стоп» (включается настройкой).
- Журналы, которые ведёт сервер: перезагрузки ПК (источник: авто/API/веб/приложение/админ), ручная остановка службы, разблокировки, тех. режим, изменения оборудования (было/стало), авиарежим (в т.ч. неверные пароли, изменение его базы), удалённый доступ (LanDesk), использование игровых аккаунтов, нехватка игр, процессы.

## Аккаунты игр (детали)
- Steam: автовход через SteamCMD; коды Steam Guard забираются **с почты по IMAP** (все почты аккаунтов пересылаются на один ящик, пароль приложения). Двухфакторный сценарий и второй лаунчер (Rockstar, Xbox) настраиваются отдельно.
- Возрастное ограничение игры требует полной регистрации; чёрный список умеет блокировать «выдачу аккаунтов» отдельно от входа.
- Аккаунт закреплён за ПК, пока занят; освобождение логируется; «лог нехватки игр» показывает спрос.

## Прочее серверное (не для оболочки, но важно для общей картины)
Касса и фискализация (АТОЛ, облачные кассы, ТС ПИоТ/«Честный знак»), склад и автозаказы (в т.ч. «умный» режим по зонам запаса), iiko-интеграция, MLM/рефералка, лояльность по группам, промокоды, сертификаты, SMS/звонки/e-mail/Telegram, тикеты, шкафчики на реле (Sonoff, SENET, RODOS), ТВ-консоли (приложение LANGAME TV, пароль разблокировки из UUID), Hotspot Wi-Fi, мобильные приложения (LANGAME App для гостей, BUSINESS для владельцев), агрегатор langame.ru, турнирная платформа CS2, сервис поддержки LanChat с «быстрыми действиями».
