## 1. Яндекс Вебмастер

1. Открой [https://webmaster.yandex.ru](https://webmaster.yandex.ru)
2. Добавь сайт `https://mirage-ptg.ru`
3. Подтверди домен (DNS TXT или HTML-файл / meta-тег)
4. В разделе «Индексирование» → «Файлы Sitemap» добавь: `https://mirage-ptg.ru/sitemap.xml`
5. Проверь «Переобход страниц» для `/`, `/clubs/mirage-pro`, `/clubs/mirage`, `/prices`, `/faq`
6. Через 1–2 недели смотри «Поисковые запросы» по ключам: компьютерный клуб Пятигорск, Мираж PRO

Если нужен meta verification — пришли код, добавим в `src/app/layout.tsx`.

## 2. Google Search Console

1. Открой [https://search.google.com/search-console](https://search.google.com/search-console)
2. Добавь ресурс типа **Domain**: `mirage-ptg.ru` (предпочтительно) или URL-prefix `https://mirage-ptg.ru`
3. Подтверди через DNS TXT у регистратора / Cloudflare DNS
4. «Файлы Sitemap» → добавь `https://mirage-ptg.ru/sitemap.xml`
5. «Проверка URL» для главной и обоих клубов → «Запросить индексирование»
6. Мониторь «Эффективность» и «Страницы» (ошибки индексации)
